## Why

Loomwright already records the flaws found by the 2026-10-26 audit and by the factory's own
change reports, but several of the highest-value ones were never closed: the sandbox has no
nesting guard, the committed plugin bundle is not reproducible from every working directory,
two package-runner aliases bypass the shell guard, and the TUI polls every run's usage for a
screen that shows one run. A few smaller correctness and test-quality gaps sit beside them.

This is a bounded correctness-and-structure pass over the current tree. Findings come first:
every candidate is re-verified, stale and already-fixed items are closed instead of re-fixed,
and anything beyond the eight-task cap is named as a follow-up rather than silently dropped.
There are no new features, no protocol events, no new commands, and no contract changes.

## What Changes

- Add the nesting marker to the sandbox: the gate runner and the plugin's shell hook mark the
  command they wrap with `AI_FACTORY_SANDBOX=wrapped`, and `sandboxEnabled` returns false when
  it sees that marker. The ADR records that the guard supersedes the workspace exception; the
  workspace's `"off"` setting stays a manual, protected-file flip after landing.
- Pin the plugin build root so `templates/plugin/factory-plugin.txt` is byte-identical from the
  repository root and from any subdirectory, and regenerate the committed bundle.
- Route `npx` and `pnpx` through the same wrapped-command, publish and global-install checks as
  `bunx`; record the decision in a new ADR.
- Honour `-h`/`--help` only as the first token after the command name, so flag values, files
  named `-h` and positional text after `--` reach the command.
- Extract the TUI status source and control orchestration into `packages/tui/src/model/`, and
  make an open run's poll fetch only that run's status and usage ledger.
- Put the packed-tarball artifact list in one script used by both `ci.yml` and `release.yml`,
  and correct ADR-0047 with the measured `dist/tui.js` size and how it was measured.
- Replace the wall-clock frame assertion in the `status --watch` test with a wait for observed
  frames, so it is green across repeated parallel runs.
- Establish the silent-catch rule: every `catch` without a binding states its fallback, and a
  failure the user needs is surfaced through `status` or `doctor`; fix the one doctor site that
  hides an unreadable `package.json`.
- Close the report and audit follow-ups with a verdict: S11/S14 residual risk is stated in
  ADR-0026, G1 stays a cost-gated follow-up, G9 is intentional, P20 is a known limit, TUI
  replay goldens are reported as a follow-up, and the already-fixed items are not touched.

## Capabilities

### New Capabilities

- `sandbox-enforcement`: the nesting marker, the guard ADR update and the recorded residual
  risk for hosts without Seatbelt.
- `cli-arguments`: when `-h`/`--help` is help and when it is a value.
- `error-handling`: the silent-catch convention and the failures that must be visible.

### Modified Capabilities

- `agent-shell-guard`: `npx` and `pnpx` are inspected as the command they wrap, and the alias
  decision is recorded.
- `build-artifact-hygiene`: the plugin bundle is cwd-independent, one artifact list governs the
  packed tarball, and ADR-0047 states the measured TUI bundle size.
- `compatibility-surface`: the named sandbox, TUI and alias ADRs may be corrected without
  weakening the historical-material scan.
- `factory-tui`: an open run's poll reads only that run, and status/control wiring lives behind
  injectable modules instead of the entry file.
- `typed-event-stream`: the `status --watch` suite drives frames from observations, not a fixed
  wall-clock window.

## Impact

- **Repo:** `loomwright` only (core, cli, tui, scripts, workflows, tests, ADRs).
- **APIs:** no protocol events, command names, flags or `status --json` shapes change. The only
  CLI surface change is that `-h`/`--help` is help in one position and a value elsewhere.
- **Contracts:** none configured, none changed.
- **Data:** no migration and no state-file shape change.
- **Protected files:** `factory.config.jsonc` stays `"off"`; `.opencode/` and
  `factory.lock.json` are regenerated by `loomwright update` after landing. The workspace flip
  to `"auto"` is a manual post-landing edit. `openspec/specs/` is not edited.
- **Follow-ups:** the shell.ts split, a real JS/TS parser, `bench ponytail`, TUI replay goldens
  for questions/help and any finding beyond the eight-task cap stay reported, not fixed.
